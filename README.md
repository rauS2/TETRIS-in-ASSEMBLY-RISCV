# TETRIS-in-ASSEMBLY-RISCV
Recriação do jogo TETRIS na linguagem Assembly do processador RISCV

Baixe o arquivo "TETRIS_ASSEMBLY.7z"

Extraia o arquivo, abra a pasta "TETRIS_ASSEMBLY", e depois o RIPES-km.
Execute o arquivo "Ripes", e após aberto, mude o processador para o "Single-cycle processor".
Carregue no simulador, o arquivo "TETORIS_FINAL.s", localizado na pasta "TETRIS_ASSEMBLY", modifique o file type para source_file e pressione o "ok".
No canto esquerdo do ripes, va em I/O e selecione o LED Matrix e o Keyboard.
Execute o simulador com o "Fast Execution".
Deixe o Keyboard selecionado para conseguir usar o "w a s d" do seu teclado e controlar o jogo.
Instruções de jogabilidade no inicio do codigo presente na aba "editor".
